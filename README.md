# FinPulse - Personal Finance & Budget Tracker

**FinPulse** is a modern, responsive personal finance management web application designed to help you track income, monitor expenses against monthly budget goals, analyze cash flow with interactive charts, and simulate Python-backed data analytics and receipt OCR scanning.

---

## 🚀 Key Features

1. **Financial Dashboard & Metrics**
   - Real-time calculation of total net worth, monthly income, monthly expenses, and savings rate.
   - Interactive cash flow trend analysis and category breakdown charts powered by **Chart.js**.

2. **Transaction Ledger & Filtering**
   - Record both income and expense transactions with custom categories (*Housing, Food & Dining, Transportation, Entertainment, Utilities, Salary, Freelance, Other*).
   - Instant search and category filtering.
   - Persistent local storage so your data remains saved between sessions.

3. **Monthly Budget Goals**
   - Set category-specific spending limits with dynamic progress bars that change color as you approach or exceed your budget.

4. **AI Receipt OCR Scanner Simulation**
   - Select sample vendor receipts (Grocery, Gas, Dining, Electronics) and simulate automated Python/Tesseract OCR extraction to log expenses effortlessly.

5. **Python Backend Console Simulation**
   - View real-time simulated Python (`pandas`, `numpy`, `scikit-learn`) runtime logs and AI-driven financial advisory insights.

6. **CSV Export**
   - Export your complete financial transaction history to a CSV file with a single click.

---

## 🛠️ Technology Stack

- **Frontend Structure:** HTML5, Tailwind CSS (via CDN) for modern styling.
- **Interactivity & State:** Pure JavaScript (ES6+) with browser `localStorage`.
- **Data Visualization:** Chart.js.
- **Icons & Fonts:** Font Awesome 6, Google Fonts (Inter).

---

## 📦 How to Run

Because FinPulse is built as a self-contained, single-file application (`index.html`), running it requires **zero installation or backend server setup**:

1. Save `index.html`  into the same folder on your computer.
2. Double-click `index.html` to open it directly in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Apple Safari).
